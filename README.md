# Sistema RMS

Sistema de protocolos de processos — Roseno, Morais & Sexto Advogados.

## Estrutura
- `frontend/` — interface (React + Vite). `cd frontend && npm install && npm run dev`
- `backend/`  — API e regras de negócio
- `database/` — scripts SQL (schema, seeds, migrations)
- `docs/`     — documentação (requisitos, diagramas)
